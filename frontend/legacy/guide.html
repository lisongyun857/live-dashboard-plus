GETTING STARTED

把电脑和手机都接进面板

手机用 MacroDroid 宏上报，电脑跑一个 PowerShell 小 agent（自带 AES 加密），服务部署在服务器上，设备发 POST、面板拉数据展示。所有配置都能在管理面板里完成。

手机接入（MacroDroid）

无需安装 App，用宏自动上报当前应用

1

拿到手机令牌

第一次启动服务时会自动生成 config.json，其中 devices 里 my-phone 的 token 就是手机令牌（启动日志里也会打印一次）。也可以直接在 管理面板 里查看、复制或重新生成令牌。

令牌相当于密码，不要发到公开群聊或截图里。想换令牌，在管理面板里一键重新生成即可。

2

确认上报地址

手机和电脑连同一个 Wi-Fi 时，用下面这个地址（如果部署到了服务器，就是服务器的公网地址）：

/api/report
3

在 MacroDroid 新建宏

触发器：先加“应用启动/切换”（Application Launched / App Changed），把常用的应用勾上；再加一个“定时器”每 1 分钟触发一次，避免长时间停留时状态不刷新。

动作：添加“HTTP 请求”（HTTP Request），按下表填写：

字段填什么
方法POST
URL上一步的地址
内容类型application/json
请求头Authorization: Bearer <手机令牌>
请求体见下方 JSON

请求体里的 {app_package}、{app_name}、{battery} 都是 MacroDroid 的魔变文本，插入时会自动替换成实际值。不确定写法时，点输入框旁的「…」按钮，从列表里插入「前台应用名称 / 前台应用包名 / 电池电量」，宏会自动填对。

{
  "app_id": "{app_package}",
  "app_label": "{app_name}",
  "battery_percent": {battery}
}

如果某些机型没有 {battery}，把这一行删掉也能正常工作。想同时上报窗口标题，可以加 "window_title": "{window_title}"（聊天、银行等私密应用会自动隐藏标题）。

如果你的 MacroDroid 版本找不到自定义请求头，也可以把令牌放到 URL 后面：/api/report?token=<手机令牌>，效果一样。

4

测试一下

可以在电脑上先用 curl 验证令牌和地址（把地址与令牌换成你自己的）：

curl -X POST "http://127.0.0.1:3000/api/report" \
  -H "Authorization: Bearer <手机令牌>" \
  -H "Content-Type: application/json" \
  -d '{"app_id":"com.tencent.mm","app_label":"微信","battery_percent":73}'

返回 {"ok":true} 就说明通了，面板上会立刻出现这台手机。

电脑接入（PC Agent）

Windows 自带 PowerShell 即可运行，敏感信息全程加密上报

1

拿到电脑令牌

打开 管理面板，登录后在「设备管理」里找到电脑设备，复制令牌（首次登录的密码在服务第一次启动的日志里打印过，也可以在面板里修改）。

2

运行 agent

把项目里的 agent/pc-agent.ps1 拷到电脑上（比如 D:\live-dashboard\agent\），在 PowerShell 里执行：

powershell -ExecutionPolicy Bypass -File agent\pc-agent.ps1 -ServerUrl http://你的服务器地址:3000 -Token 电脑令牌

agent 会每隔几秒检查一次前台窗口，应用切换或每 60 秒心跳时上报；报文自动走 AES-256 加密 + HMAC 防篡改，无需额外配置。可用 -IntervalSeconds 调整检查间隔，Ctrl+C 停止。

3

开机自启（可选）

新建一个 start-agent.cmd（内容就是上面那条命令），按 Win+R 输入 shell:startup 回车，把 cmd 文件的快捷方式放进去，开机就会静默上报。

部署到服务器

后端和前端是同一个 Node 服务，一次部署全部搞定

1

安装 Node 并启动

服务器装好 Node.js 18+，把整个项目目录传上去（比如 /opt/live-dashboard），然后：

node server.js
# 后台常驻（推荐 pm2）
npm i -g pm2
pm2 start server.js --name live-dashboard
pm2 save && pm2 startup

首次启动会自动生成 config.json 与管理面板密码（打印在日志里），并创建 data/ 数据目录。

2

开放端口 / 反向代理

在云厂商安全组放行 config.json 里的端口（默认 3000）；或者用 Nginx / 宝塔把 80/443 反向代理到 3000，对外只暴露 80/443。

3

开启 HTTPS（强烈建议）

手机 MacroDroid 上报的是明文 JSON，必须配 HTTPS 才能保证传输隐私。两种方式任选：

方式 A：Nginx / Caddy 反向代理 + Let's Encrypt 证书，服务本身保持 HTTP；
方式 B：直接启用内置 HTTPS，在 config.json 里加：

{
  "https": { "enabled": true, "cert": "/etc/ssl/live-dashboard/fullchain.pem", "key": "/etc/ssl/live-dashboard/privkey.pem" }
}

证书路径填 fullchain 与私钥的绝对路径，重启服务生效；证书读取失败会自动回退 HTTP 并在日志里提示。

加密传输与隐私说明

敏感信息（窗口标题等）密文上送，服务器只存脱敏结果

电脑端：agent 的每次上报都是一个加密信封——用设备令牌在本地派生密钥，AES-256-CBC 加密 + HMAC-SHA256 完整性校验（encrypt-then-MAC），服务器先验签再解密，抓包只能看到密文；令牌本身不随请求明文之外传输（仅作密钥来源与鉴权）。

手机端：MacroDroid 无法在宏里做应用层加密，上报的是明文 JSON，因此请务必让上报地址走 HTTPS（反向代理或内置 HTTPS 均可），浏览面板同样建议全程 HTTPS。

服务端：聊天、邮件、金融、密码类应用会整体匿名化为「私密应用」，窗口标题原文不落盘、不下发到前端。

统一管理面板：站点名称、离线判定、数据保留天数、设备与令牌增删、清空数据、修改管理密码，都在 /admin 里完成，保存即时生效，无需重启服务。

在线测试上报

令牌只保存在本次页面内存里，刷新即清除；测试记录会真的出现在面板上。

隐私说明：面板是公开只读的。服务端不会保存窗口标题原文；聊天、邮件、金融、密码类应用会整体匿名化成“私密应用”，只保留使用时长。
